# KotlinSprint

Небольшой набор задач и мини-проектов по курсу Kotlin. Здесь я разбирался с базовым синтаксисом языка, коллекциями, функциями, ООП и другими фундаментальными вещами.

## Что внутри

- Учебные примеры и упражнения на Kotlin
- Пошаговое усложнение задач
- Разбор базовых конструкций языка

## Как запустить

Открыть проект в IntelliJ IDEA (или другой IDE с поддержкой Kotlin) и запустить нужный `main`-класс / тесты из IDE.

## Статус проекта

Учебный репозиторий. Нового функционала не планируется.
